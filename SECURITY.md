# Reporting security issues

This repository is a portfolio showcase of the Altitut CRM and is not deployed as a
public service. If you spot a problem in this code, please contact the repository owner
through their [GitHub profile](https://github.com/dbrawla) rather than posting details
in a public issue.

For issues in the upstream project this was forked from, see
https://listmonk.app/docs/security-reports/ first.
